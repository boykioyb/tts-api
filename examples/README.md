# Voice demos

One demo clip per preset voice, each read in that voice's **default style**. Generated by
[`generate_demos.py`](generate_demos.py) — the same phrase for every voice so you can
compare them directly:

> *"Xin chào, tôi là {tên}. Đây là giọng đọc tiếng Việt của VieNeu — bạn thấy nghe thế nào?"*

## Regenerate

```bash
pip install vieneu lameenc
python examples/generate_demos.py
```

Files land in `examples/demos/<voice_id>.mp3` (48 kHz mono, 128 kbps). First run
downloads the VieNeu weights from Hugging Face.
